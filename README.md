# 🎯 GoalTracker

GoalTracker is a simple and intuitive web application designed to help users create, manage, and track their personal goals efficiently.

It allows users to organize their objectives, stay motivated, and monitor progress in a clean and minimal interface.

🔗 Live Demo: https://goal-tracker-by-imane.vercel.app

---

## 📌 About The Project

GoalTracker was developed as a personal project to practice web development fundamentals and build a productivity-focused application.

The goal of this project is to provide a lightweight tool that helps users:

- Define clear goals
- Track progress easily
- Stay organized and motivated
- Manage daily or long-term objectives

---

## ✨ Features

- ✅ Add new goals
- ✅ Track goal progress
- ✅ Simple and clean user interface
- ✅ Lightweight and fast
- ✅ Responsive design
